# Servisni Intervali

Privatna iPhone PWA za evidenciju vozila, servisa, dokumenata i podsjetnika za gume.

**Live:** https://dadolinoo.github.io/servisni-intervali/

Potpuno odvojeno od DH-Logix. Podaci su na uređaju, uz automatski backup u oblak (Prijava e-mailom i kodom u Postavkama) i ručni JSON backup.

## iPhone

Upute: [IPHONE.md](./IPHONE.md) — Safari → Podijeli → Dodaj na početni zaslon.

## Izrada i objava

Alati i predložak su u `tools/`. Koraci za novu verziju: [tools/PUBLISH.md](./tools/PUBLISH.md).
